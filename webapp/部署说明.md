# 童健韶华 · AI 健康成长助手 —— 部署说明

一个可扫码访问、可离线打开的 PWA 小工具，整合三块能力：
1. **AI 体质评估与运动指导**（填身体数据 → AI 生成 4 板块健康报告）
2. **屏幕时间 · 以动代屏**（屏幕使用评估 + 趣味替代运动 + 健康用网契约）
3. **理念与政策依据**（以动代屏、AI 赋能全民健身）

## 一、整体架构与安全要点
- 前端是纯静态 PWA（HTML/CSS/JS），部署到任意静态托管即可，可离线缓存、扫码访问。
- **AI 调用必须走后端代理**，密钥（通义千问 API Key）只放在代理的环境变量里，**绝不明文写进前端**。
- 前端「设置」里填你自己的代理地址；也可选「直连个人 Key」（仅本机保存，适合自己临时用，公网分享建议用代理）。

## 二、部署后端代理（隐藏密钥，只需做一次）
1. 登录 Cloudflare 控制台 → **Workers 与 Pages** → 创建 **Worker**。
2. 把 `worker/worker.js` 的内容完整粘贴进去并部署。
3. 进入该 Worker → **设置 → 变量（环境变量）**，添加：
   - 变量名 `DASHSCOPE_KEY`，值 = 你的通义千问 `sk-...`（保存为「加密」/Secret）。
4. 部署后你会得到一个地址，形如 `https://你的名字.workers.dev/`。
   （你原有的 `damp-tooth-b307.yanzongning.workers.dev` 若仍可用，直接用即可。）

## 三、部署前端（扫码即用）
- 用 WorkBuddy「一键部署」把本 `webapp` 目录作为静态站点发布，得到 https 链接。
- 把该链接生成二维码，别人扫码即可打开。
- 想长期稳定的话，也可把 `webapp` 目录整体上传到 Cloudflare Pages / GitHub Pages / 任意静态托管。

## 四、首次使用（使用者侧）
1. 扫码打开小程序 → 右下角「⚙️ 设置」。
2. 调用方式选「后端代理」，填入你在第二步得到的代理地址，保存。
3. 回到「评估」页填数据生成报告；或到「护体」页做屏幕时间评估、生成契约。
4. 浏览器会提示「安装」到桌面，安装后断网也能打开页面（AI 生成需联网）。

## 五、目录结构
```
webapp/
├── index.html              # 主页面（三模块 + 设置）
├── css/style.css
├── js/app.js              # 导航 / 设置 / PWA 注册 / 离线提示
├── js/assess.js           # 模块A：AI 体质评估
├── js/screentime.js       # 模块B：屏幕时间 / 以动代屏
├── vendor/marked.min.js   # 本地化的 Markdown 解析（离线可用）
├── manifest.webmanifest   # PWA 清单
├── service-worker.js      # 离线缓存
├── icon.svg
└── worker/worker.js       # 后端代理（部署到 Cloudflare）
```
