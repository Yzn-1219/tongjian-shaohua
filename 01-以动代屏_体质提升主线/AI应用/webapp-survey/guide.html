现场怎么走

照这个顺序做就不会乱

开场前 3 分钟：投课前码第 2 页

投影 PPT 第 2 页（课前码），说一句「先花 40 秒填一下，不记名」。等人扫得差不多了再开始讲。填过的人屏幕上会出现「讲完了？去填课后问卷」——提醒他们先别点，那是给收尾用的。

讲的过程中：不动它

正常讲完全部页面。中途不需要催填，后台会自己在后台攒数据，每 15 秒刷新一次。

收尾：投课后码最后一页

换到课后码那一页，同样请学生再扫一次。要是有人课前那份还开着，直接点屏幕上那个「去填课后问卷」按钮也行，效果一样。

讲完当场：打开后台看数、导出 CSV

手机扫「后台看板」那张码，输口令进。看一眼课前/课后两份数字和五项指标的差值，然后点「导出 CSV」——只有导出过一次，顶部黄条才会变绿，那才叫留了档。

后台能看什么

数据员重点
区块看到什么
顶部两个数课前收到多少份、课后收到多少份
谁在用App 打开、问卷打开/提交、AI 调用次数与 token
五项指标灰条课前 / 蓝条课后，右侧标出差值（pt）
行为基线仅课前：屏幕时间 ≥4h 占比、主动锻炼 ≤2 档占比
课后附加帮助度均分、打算何时开始
操作「刷新数据」「导出 CSV」
  • 差值怎么读：课后减课前，正数才是提升。课前 60% → 课后 85%，就是 +25 pt。
  • 五项指标口径：危害认知＝打 4–5 分的占比；算分清楚度＝选「基本清楚/很清楚」；政策知晓＝选「知道挂钩/清楚标准」；重要性认同＝4–5 分；行动意向＝选「打算开始/已经在坚持」。
  • 留档：导出的 CSV 带 BOM，Excel 直接打开不乱码，文件名带时间。
  • 别只看「黄条变绿」：它记的是这台电脑的浏览器，换设备会重新显示未导出。关键是把文件存进网盘或 U 盘。

AI 功能怎么用

学生也能玩，不用申请任何 Key

🤖 AI 小童

综合问答：体测怎么算分、评优怎么挂钩、屏幕时间怎么控。知识库只装核实过的口径，超范围它会说「不确定」。

📋 体质评估

填身高体重腰臀围，AI 出一份体质报告，带 BMI、基础代谢和训练建议。

🤔 AI 教练

按打卡记录和身体数据，生成一份结构化训练+饮食计划。

  • 第一次用要先解锁：进入任一 AI 功能前，到「设置 → 🔌 AI 服务」选「本站默认 API」，输入调用码 tjsh2026。输一次就记在这台设备上，以后不用再输。
  • 也可以用自己申请的 Key：同一个卡片里选「我自己的 API」，填上自己的 Key 即可（只存本机，不上传）。
  • 没连上会怎样：不会只甩一句「生成失败」，会弹一张提示卡说「当前还没有连接到 AI」，点按钮直接跳到那张 AI 服务卡片，配好就能继续用。
  • 投影演示前先自己试一次：确认这台设备已经解锁，免得当场卡住。
5

要换 API Key 时（队长操作）

不用改代码、不用重新发布
  • 打开后台看板 → 输口令 → 滑到最下面「🔌 AI 服务配置」卡片。
  • 改显示名称 / 接口地址 / 模型名 / API Key / 调用码，点「保存到云端」。
  • 点「测试能否调通」：通了会显示模型回的一句话；没通会说明原因（Key 错、模型名不对、地址不通）。
  • 全站所有设备下次打开页面就换成新的；已经开着页面的刷新一下即可。
  • API Key 默认打码，点「显示」才看得到——投影上看板子不会把 Key 亮给全班。

现在的默认是通义千问 qwen-flash。想换中转站也行，接口地址填到 /v1/chat/completions 就自动按 OpenAI 兼容格式调用。

怎么知道是不是新版

  • 看左下角：任意页面左侧栏最下面有一行「版本 vX.Y.Z · 日期」，鼠标停上去会显示这次改了什么。
  • 手机上看：点 ☰ 打开菜单拉到底，同样能看到那行版本号。
  • 对上了就是最新：跟群里通知的版本号一致，说明已经刷新到新版；不一致就刷新一下页面。
