# 童健韶华志愿服务队资料库

> GitHub 仓库：https://github.com/Yzn-1219/tongjian-shaohua （公开仓库）

## 项目概况

围绕"青少年体质健康提升 + 志愿服务"主线，团队分三条业务线开展社会实践，并配套开发了多款 AI 数字工具：

| 业务线 | 主题 | 落地地点 |
| --- | --- | --- |
| 以动代屏 | 儿童防网瘾 + 体质提升（网络素养启蒙 + 趣味运动会） | 威海环翠区 |
| 资润启梦 | 国家学生资助政策宣讲（助学贷款 / 助学金 / 励志奖学金） | 菏泽 |
| 麦香传韵 | 胶东花饽饽 / 文登喜饼非遗调研 | 威海文登 |

## AI 数字工具

- **webapp**（以动代屏完整版）：AI 体质评估 + 趣味运动菜单 + 理念政策 + 关于我们。
- **AI体质检测助手**（独立版）：纯 AI 体质评估，自包含 PWA。
- **webapp-fitness**（健身模块）：训练记录 + 身体数据 + AI 教练 + 目标设定。
- **webapp-aid**（资润启梦）：山东省学生资助政策介绍 + AI 问答。

> 各应用均为 PWA，部署说明见对应 `AI应用/` 子目录内的文件。AI 调用统一使用 DashScope 原生端点，Key 由使用者扫码/填写，密钥经 `TJS1:` 前缀 + XOR/Base64 混淆，不落地明文。
