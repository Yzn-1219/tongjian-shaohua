## 一、这支队伍做了什么

一个判断：青少年体质在往下走，屏幕时间在往上走。我们做的事很小——用运动把孩子从屏幕前拉出来，再用工具补上家长"不会带"的那一块。

三条业务线，三个地方：

| 业务线 | 做什么 | 落地 |
| --- | --- | --- |
| **以动代屏** | 儿童防网瘾 + 体质提升：网络素养启蒙课 + 趣味运动会 + AI 体质评估 | 威海市环翠区（黄家皂幼儿园、蓝海社区、西海社区） |
| **资润启梦** | 国家学生资助政策宣讲，配套自助查询与 AI 问答工具 | 菏泽 |
| **麦香传韵** | 胶东花饽饽、文登喜饼非遗调研 | 威海文登 |

2026 年 7 月 2—8 日，六个人在威海做了七天，覆盖一百多名儿童，回收问卷两百余份。
项目获院级社会实践一等奖；纪实稿刊发于中国青年网"中青校园"（原题《以动代屏 向光而行》，刊发题《跳出屏幕方寸地，跑向健康新天地》）。

## 三、五个 AI 工具

都是纯前端 PWA，打开即用，不用装 App。AI 调用统一走 DashScope（通义千问）原生端点，**用户自填 Key，密钥只存在本机浏览器**，不落到任何服务器。

| 工具 | 做什么 | 位置 |
| --- | --- | --- |
| **体质问卷系统** | 班级宣讲现场用：课前/课后双份问卷 + AI 小童问答 + 后台实时看板（五项指标前后对比、导出 CSV）。已部署上线，扫码即填 | `01-.../AI应用/webapp-survey/` |
| **AI 智能健康应用系统**（V11） | 完整版：AI 体质评估 + 训练打卡 + 身体数据 + AI 教练 + 目标设定，六标签一体化 | `01-.../AI应用/童健韶华_AI智能健康应用系统/` |
| **webapp-fitness** | 健身模块独立版：训练记录、身体数据曲线、AI 教练生成计划 | `01-.../AI应用/webapp-fitness/` |
| **AI 体质检测助手** | 独立版，只做体质评估报告，最轻量 | `01-.../AI应用/AI体质检测助手/` |
| **webapp-aid**（资润启梦） | 山东省学生资助政策介绍 + AI 问答，政策条文可溯源 | `02-资润启梦_资助政策/AI应用/` |

### 问卷系统（最常用的一个）

站在讲台上要用的就是它：

1. **课前**：投影第 2 页的二维码，学生扫码填 7 道题，约 40 秒
2. **讲课**：正常讲，后台自己攒数据
3. **课后**：投影最后一页二维码，同样 7 道题再填一遍
4. **讲完当场**：手机扫码进后台，看课前课后对比，点「导出 CSV」留档

两个码只差链接末尾的 `&p=pre` / `&p=post`，课前是青绿、课后是深蓝，**颜色就是为了让学生不扫错**。
详细操作见 `webapp-survey/使用说明.md`，给队里人看的版本见 `webapp-survey/guide.html`。

> 数据不记名，只统计到全年级一张总表；不采集姓名、学号，也不采集 API Key 和生成内容。

## 四、怎么看这个项目的方法

如果只看一份材料，看这两个：

- **想了解做了什么** → `01-.../报告文档/` 里的社会实践报告定稿
- **想知道怎么做的** → `01-.../班级宣讲/以动代屏·三下乡实践复盘.pptx`（30 页，按"看题—选题—做题—交卷"四步讲完整打法）

四步的骨架是：**看题**决定方向，**选题**决定阵容，**做题**决定质量，**交卷**决定这件事最后能留下什么。
四步之外还有三件事缺一不可：团队、能力、AI。
