# 视觉设计稿 - 暖阳信语·星光伴成长 实践汇报 v1

> 本PPT采用 **白+蓝科技风**：与「以动代屏·童健韶华」v2 同套色板，保证资料库视觉统一。
> 主诉求：温柔陪伴感 + 专业可信 + 简洁有力。无团队徽章/活动照，所有视觉靠"几何+渐变+大数字+图标"承担。

---

## 1. 画布与版式

- **画布尺寸**：1280 × 720 px（16:9）
- **全局版式**：三区布局
  - A 区（标题块）：0 ~ 100px
  - B 区（内容区）：100 ~ 660px
  - C 区（页脚条）：660 ~ 720px

## 2. 配色系统（与 v2 一致）

| 角色 | hex | 用途 |
|---|---|---|
| 主色 深蓝 | `#0B2545` | 主标题 / 重数据 / 强调边 |
| 辅色 中蓝 | `#1E88E5` | 数据条 / 强调卡片 / 数字高亮 |
| 辅色 浅蓝 | `#E3F2FD` | 卡片底 / 标签胶囊 / 装饰条 |
| 辅色 暖黄 | `#FFD166` | 仅用于"暖阳"系列点缀（信封/星星/陪伴）|
| 主色 白 | `#FFFFFF` | 全局背景 / 卡片正面 |

渐变锚点：`#E3F2FD → #FFFFFF → #D6EBFF`（封面/封底）

## 3. 字体系统

- **微软雅黑 / Microsoft YaHei**（标题）
- **思源黑体 / Source Han Sans CN**（正文）

字号：
- 封面大标题 56
- 章节大标题 32
- 卡片标题 20
- 正文 14
- 大数字锚点 72

## 4. 视觉元素库

- **卡片**：圆角 12px / 阴影 `0 4px 16px rgba(11, 37, 69, 0.08)`，左侧 4px 深蓝竖条 `#0B2545`
- **数据条**：圆角 6px / 高度 12px / 填充 `#1E88E5`
- **标签胶囊**：圆角 16px / 浅蓝底 + 深蓝文字
- **emoji 锚点**：⭐ 🌟 💌 🎨 📚 ✉️（用作"暖阳信语"主题图标，避免生图）
- **底纹**：浅蓝径向渐变圆斑（直径 600~800px），低透明度

## 5. 5 页固定结构

| 页 | role | 主色占比 | 内容 |
|---|---|---|---|
| 1 封面 | hero | 蓝渐变 65% | 标题 + 副标题 + 时间地点 |
| 2 团队概况 | supporting | 白 65% | 指导老师 + 队长 + 5 队员 |
| 3 实践内容 | framework | 浅蓝 60% | 4 主线卡片 + 时间地点 |
| 4 实践成果 | data-heavy | 白 60% | 3 大数字 + 3 数字卡 |
| 5 总结展望 | closing | 蓝渐变 65% | 收获 + 3 改进 + 长效档案 |

## 6. 动画策略

- **页面级**：fade（淡入淡出，WPS 兼容，不卡顿）
- **元素级**：大数字锚点放大+淡入；卡片淡入+轻微上移
- **"花哨"分寸**：无弹跳/旋转/闪烁，靠"轻微运动"+"几何渐变"显科技感

## 7. 内容来源约束

- 5 页**全部内容**严格来自附件5 实践报告 + 附件4 活动记录表
- 团队成员、班级、学号、活动时间、地点、数据均与 docx 一致
- 演讲词每页 ≈120~150 字，与 docx 同义改写（不超纲）
